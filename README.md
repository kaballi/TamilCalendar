# தமிழ் நாட்காட்டி | Tamil Calendar

Discover today's Tamil date at a glance. **தமிழ் நாட்காட்டி** is a free Tamil calendar for checking the Tamil day, month, festivals, and more—designed for Tamil speakers everywhere.

[Open the Tamil Calendar](https://tamil-thirunaal-calendar.lovable.app/) · [View the monthly calendar](https://tamil-thirunaal-calendar.lovable.app/month)

## Your Tamil calendar, all in one place

- **Today's Tamil date:** See the Tamil weekday, month, and date alongside the English calendar date.
- **Monthly calendar:** Browse Tamil or English months, move between months and years, and view festival dates.
- **Find your Tamil birthday:** Enter a birth date to discover its Tamil weekday, month, and date, then jump to it in the calendar.
- **Festival calendar:** Spot Tamil festivals on the monthly view and see the festivals observed today.
- **Moon phase and sunrise:** View the current moon phase and estimated sunrise time. Sunrise uses your device location when permission is granted; otherwise, it defaults to Chennai.
- **Made for Tamil:** Switch between Tamil and English date displays, with optional Tamil numerals.

## Built with

React 19 · TypeScript · TanStack Start and Router · Tailwind CSS 4 · Vite · Vitest
